# Contributing to TakeLab

Keep the project focused on daily video review: faster decisions, reliable local files, and useful production records. Please discuss large changes in an issue before starting them.

## Setup

Use Node.js 22.12+ and `npm ci`. Run `npm run dev` to open the workbench at `http://127.0.0.1:4173`. The included demo is enough to work on most features; don't commit private source footage or prompts.

Before submitting a pull request:

```sh
npm run format
npm run check
npx playwright install chromium
npm run test:e2e
```

Use `--with-deps` when installing Chromium on a fresh Linux environment. Browser tests create their own profile, so they should not touch your normal workspace.

## Change expectations

- Describe the concrete problem, changed behavior, and checks you ran. Include a screenshot for visible changes.
- Update both language strings when changing UI text. Keep empty states, failure recovery, keyboard access, and narrow layouts usable.
- Test data integrity and media behavior, not implementation details. Storage migrations and archive-format changes need backward-compatibility tests.
- Avoid adding remote calls, telemetry, model SDKs, paid services, or heavyweight video dependencies to the default workflow without discussion.
- Keep imported files as blobs, revoke object URLs, release video decoders when unused, and bound archive memory.
- Treat imported archives as untrusted. Do not bypass validation or render prompts/notes as raw HTML.
- Match existing TypeScript formatting. Commit messages and code comments are in English.

## Demo assets

The nine bundled videos are generated by `scripts/generate_demo.py` using original mathematical artwork. To regenerate, install Python with NumPy and Pillow plus an FFmpeg executable on PATH, then run the script from any directory. It writes the videos and `src/demo-assets.json` deterministically. FFmpeg and Python are development-only tools, not shipped app dependencies.

## Reporting problems

Use the bug report template with browser/version, OS, source codec/resolution/duration and reproduction steps. Share only synthetic or publicly shareable clips. Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
