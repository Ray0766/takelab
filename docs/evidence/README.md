# Reproducible evidence

Generated locally from TakeLab's original MIT-licensed procedural clips and FFmpeg test patterns. No client media, genuine model benchmark or paid generation API was used.

Start with [the validation receipt](../VALIDATION.md), [selection record](record.md), and [full portable project](decision-with-media.takelab.zip). The portable project includes its media. The separate JSON/Markdown capture the pre-relink snapshot; IDs and decision associations are unchanged.

`sync-before.json` is the original baseline. `sync-after-run2.json` retains the corrected-build run that missed the 80 ms p95 target. `sync-after.json` is the final run. Do not omit the failed-target receipt when summarizing results.

Images and video are actual app/test exports, not design mockups. Video IDs match the records. Generated files are excluded from formatting to preserve original output.
